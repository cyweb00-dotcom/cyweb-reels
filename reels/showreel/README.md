# CYWEB motion showreel (22 s, 1080x1920, 30 fps, 120 BPM)

Motion-design style reel for CYWEB, inspired by the rhythm of a motion showreel (one idea per beat), adapted to the CYWEB look: black with one blue glow, big type, ends on the start frame so it loops. Nothing copied from the reference.

| Time | Beat |
|---|---|
| 0-2 s | Hook: blue dot splits into three, "NO WEBSITE?" slams in |
| 2-4 s | Blue panel: "CUSTOMERS / CAN'T / FIND YOU." one word per beat |
| 4-6.5 s | DESIGN: a shape morphs in a transform box (circle, square, triangle, flower) and becomes a website with a Book now button |
| 6.5-9 s | BUILD: a dot grid ripples, then gathers into a spinning dot sphere |
| 9-11 s | LAUNCH: a particle ring snaps into a wireframe cube |
| 11-13.5 s | GET FOUND: a glossy ribbon swoops through, a map pin drops |
| 13.5-17 s | Three spinning text rings: websites, bookings, WhatsApp, Google Maps, photos, videos |
| 17-21 s | CYWEB logo, "Websites that help local businesses grow.", cywebdev.com |
| 21-22 s | Collapses back into the blue dot (= first frame) |

Files: `index.html` (canvas animation, one time value per frame), `render.js` (frames), `audio.py` (music bed + one sound per animation), `out/cyweb-motion-showreel.mp4`.
